# Lynera v8 update

This update makes only the requested home-screen refinements:

- Moves the past and predicted labels closer to their endpoint markers.
- Keeps the Today label close to the centre marker while leaving more breathing room beneath the large date.
- Aligns the large endpoint dots with the smaller extension dots.
- Adds a little more space between the arc and the confidence pill.
- Preserves enough vertical room for the mountains, lake, and reflection to remain visible.
- Slightly reduces the two card-heading sizes relative to the large date.
- Changes the privacy sentence to “Entries stay on this device.”
- Updates the offline cache to `lynera-v8`.

## Full replacement

1. In GitHub Desktop, Fetch origin and Pull origin if available.
2. Close GitHub Desktop.
3. Back up your existing local project folder.
4. In the existing project folder, keep the hidden `.git` folder and delete everything else.
5. Copy all contents from this replacement project into the existing folder beside `.git`.
6. Reopen GitHub Desktop.
7. Commit with `Refine Lynera timeline spacing`.
8. Push origin.
9. Confirm the newest GitHub Pages Action completes both build and deploy.

## iPhone refresh

After deployment, open the Pages URL in Safari, refresh once, wait about ten seconds, fully close Safari and Lynera, then reopen Lynera from the Home Screen.
