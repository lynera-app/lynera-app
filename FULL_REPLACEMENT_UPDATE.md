# Lynera v6 full replacement

This version removes phase labels from the home screen and places a subtle glass pill below the timeline showing only the prediction-confidence percentage. It also tightens the timeline labels, refines the dotted arc extensions, reduces the Today glow, softens the aurora fade, and adds more breathing room before the daily check-in.

Use the full replacement process: pull the latest repository changes, keep the hidden `.git` directory, replace every other project file with this package, commit, and push.
